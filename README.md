# Milan Patel — Developer Portfolio

Personal portfolio website for **Milan Patel** (Full-Stack Developer), built with **Next.js 16** (App Router), **React 19**, **TypeScript**, and **Tailwind CSS 4**.

## Quick Customization

- **Resume Data & Links:** Edit [`data/data.ts`](data/data.ts) to update experience, projects (including adding `liveUrl` and `githubUrl` links), categorized skills, education, certificates, and contact details.
- **Site Metadata & GitHub Username:** Edit [`lib/site.ts`](lib/site.ts) to change the site URL, SEO metadata, or GitHub username (`MilanPatel2003`).

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Verification

```bash
npm run lint
npm run build
node --test tests/*.test.mjs
```
